# ftse-financial-distress-prediction
Python code for one-year-ahead financial distress prediction using Logistic Regression and Random Forest.
# Financial Distress Prediction in FTSE All-Share Firms

This repository contains the Python code used for the MSc dissertation
“Financial Distress Prediction in FTSE All-Share Firms Using Logistic
Regression and Random Forest Models”.

- `01_load_data.py` contains the initial data-loading and validation procedures.
- `02_split_data_analysis.py` contains the complete modelling and evaluation
  procedures, including chronological data partitioning, preprocessing,
  Logistic Regression, Random Forest, threshold selection, test-set evaluation,
  model interpretation, calibration analysis and paired Ticker-clustered
  bootstrap analysis.

The Bloomberg-derived dataset is not publicly provided because it is subject
to institutional licensing restrictions.
